## 📁 Projeto 1: Sistema de Reservas de Hotel

### Funcionalidades
- Cadastro de hóspedes (nome, e-mail, telefone, preferências de quarto).  
- Registro de quartos (número, tipo, status).  
- Reservas com datas de check-in e check-out.  
- Consulta de quartos disponíveis.

1. **Crie o banco de dados no pgAdmin:**

   CREATE DATABASE reservas_hotel;
